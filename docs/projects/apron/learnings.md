## 2026-10-06: Apron V2 shipping-assembly placeholders

- **V1 and V2 number their spare `DummyASMA` slots differently.**

  | Slot | V1 | V2 |
  |---|---|---|
  | SA4–SA7 (in the top level) | -33…-36 | not yet assigned |
  | Belt / chain | -37 / -38 | -33 / -34 |

  Copying slot rules between the two files only works for the section slots -1…-29.
- **`MyNumber` in the SA slot rules.** In V2, the "V2" in `SA3 (Apron Conveyor Assembly V2)` adds a digit run: 3, **2**, 15. So V1's `MyNumber(2)` would return 2 for every slot.
  - Use `MyNumber(1)` for the SA and `MyNumber(-1)` for the slot. They work in both files.
  - DwFormEngine doesn't evaluate model rules, so we can't test this here. Check it in the Administrator rule builder.
- **The V2 SA rules were generated by script.** 196 instance rules (SA1–SA7 × slots -2…-29) were written in one `Edit-DwProject` pass.
- **Applies elsewhere:** how `MyNumber` reads `<component set>\<instance>`, and the scripted-rule technique. Both are in [../../learnings.md](../../learnings.md) (2026-10-06).

## 2026-10-05: SectionLayout "Last" bug

- **`FirstLastInShippingAssy` compared only with the next row,** so a section followed by disabled rows was never "Last", and the lifting braces and chain holders that depend on it were deleted.
  - The user's idea, a filtered-table variable, is circular, because a variable that reads the table depends on every cell.
  - The fix that works is a helper column filled bottom-up with relative references (`NextEnabledSA`); it was tested in the engine.
- **Applies elsewhere:** never read a calculation table from inside itself ([../../formats/form-rules.md](../../formats/form-rules.md)).

## 2026-10-02: Conveyor Options frame collapses without a bottom elbow

- **Status: confirmed in the real engine, and fixed in the sandbox.** In DwFormEngine, the 09-28 sandbox project fails exactly as predicted below.
  - 24 of 5,196 states fail (straight 20–21 ft, Top Elbow 16–17 ft), all with root cause `LogoWarning.Height`/`LogoWarningVisible`.
  - With fixes 1 and 2, no state fails: 9,832 lengths, belts, picks, bottom-elbow builds, and the path that turns a bottom elbow off.
  - A third guard was added in the sandbox: `CommonSpecsExtend.Height` = `IfError(LogoWarning.Top + LogoWarning.Height,400)`, so no error in that chain can collapse the panel again.
- **Still open:** the user applied fixes 1 and 2 to the *production* project and it still fails there. The production project isn't in this repo, so it may differ from the 09-28 snapshot.
- **Symptom:** "- Conveyor Options" opens to a blank strip, and the "Motor, GearBox and Belt Options" header disappears. The motor frame's own height is always at least 24 px, so a missing header means its `Top` rule (`CommonSpecsFrame.Top + CommonSpecsFrame.Height`) is in error.
- **Error chain:** `CommonSpecsFrame.Height` → `CommonSpecsExtend.Height` (`LogoWarning.Top + LogoWarning.Height`) → `LogoWarning.Height` = `Indirect("DWVariableLengthMidSection"&ExtractNumber(SpartaLogoPositionReturn))`. When the logo box is empty, `ExtractNumber("")` is NaN, `Indirect` fails, and the error runs up through every frame below. `SkiPositionWarning.Height` has the same pattern.
- **Why the logo box goes empty:** the `none` variable (`If(BottomHorizontalLength1,"None|","None")`) tests a check box that is hidden and off without a bottom elbow, but those builds still have bottom-list sections.
  - The oiler list becomes `NoneA02|A11`, the oiler auto-selects `NoneA02`, the ski list is `A11`, and the logo list ends up empty.
  - A simulation of every length and pick found it only without a bottom elbow, with the default picks: straight 20–21 ft, Top Elbow only 16–17 ft (the logo list's first item is blank with a top run).
- **Fix:** `none` = `If(DWVariableNumberOfBottomSection>0,"None|","None")`. The `|` is needed exactly when `OILERPOS` starts with a bottom section. In the simulation every combination then passes. It also drops the bogus A11 from straight and Top Elbow only lists. Wrap the two `Indirect` warning rules in `IfError(…,0)` as a guard.
- **If production still fails after the guards:** the only elbow-dependent link left is `SpartaLogoPosition.Height` (`LengthMidSection11/1/21 >= 108`), inside `LogoWarning.Top`. The `CommonSpecsExtend.Height` guard covers that too.
- **Applies elsewhere:**
  - A blank anywhere in a Top/Height sum breaks every frame below it.
  - A hidden check box still feeds rules (see the engine facts in [../../learnings.md](../../learnings.md), 2026-10-02).
  - Tracked item `apron-conveyor-options-collapse`.

## 2026-10-01: Apron form, read for the layout-app table

- **List strings joined without a `|` merge items.** Apron's oiler list starts with `If(BottomHorizontalLength1,"None|","None")`. With no bottom elbow that check box is off, so the list comes out as `NoneA02|A03|…`. This was confirmed with the engine's own `StringFunctions.ListGetItems(list, first, count)`. The ski, E-stop and logo lists are built from it, so all four break.
- **The ClientProjects export runs on every release**, not only for new clients: `NewClientProjects` is released with all documents. The sandbox table holds 161 Apron rows, most of them test prefixes with Work Order "-". Stairs, Ladder and Start Leg release the same `NewClientProjects` document on completion, and Picking Conveyor releases a similar one, `NewClientProject`.
- **Apron has no height input and no supports.** `ConveyorTailHeight` is hidden and no rule reads it, and there is no Start Leg host. So a layout has to set the apron's elevation itself.
- **The 10 ft limit is still hard-coded.** `ftMaximumSectionLength` = 10 is read only by the three `…finallength` guards. The section counts and carry-overs in 21 variables still use a literal 10 (see [../apron.md](../apron.md)).
- **Kit hooks copied over that point at nothing:**
  - the `ExportToDB` and `ImportFromDB` macros;
  - the `EmailToCustomerCAD` email;
  - `DWVariableProjectNameFromDB`;
  - a `DataLine` query on the Kit's SQL table.
- **Defaults that aren't options:** `TypeBelt` defaults to 2.4375 (a shaft size) and `Thickness` to None, so no belt or chain is built until one is picked.
- The full table is in [../inputs/apron-inputs.md](../inputs/apron-inputs.md).
